## Why a *filtered* sittings file (the overspend guard)

`judging judge` scores a **whole** `sittings.jsonl` — there is no cell-level flag. Handing it a
full merged sittings file with `--results-dir` at a root that lacks those framings would judge
~21,840 cells (Opus-with-thinking) — hundreds of USD — with **no error**. So the re-judge feeds a
**filtered** sittings file containing only the 34 missing sittings, and the judge's resume set
(`judgments.jsonl` ∩ sittings) reduces the work to exactly the **35** missing cells. A pre-spend
assertion (`work-count == 35`) gates every invocation.

**Transcript source vs verdict layer** (they differ because roots spell subjects differently and
hold different framings):
- **unstated** transcripts ← `20260803-merged/<t>/sittings.jsonl` (canonical subject ids); verdicts
  written into `20260803-unstated-opus/<t>/` (its existing Opus judgments use the same canonical
  spelling → resume matches precisely).
- **stated/guided** transcripts ← `20260823-opus-fullgrid/<t>/sittings.jsonl` (raw provider slugs);
  verdicts written into the same `20260823-opus-fullgrid/<t>/`.

Both layers are picked up by the four-root export order in [`README.md`](README.md).

## Commands

Enumerate the missing cells and build the filtered sittings (read-only; also prints the
pre-spend work-count, which must equal 35):

```bash
uv --project workflows/analysis run python <enumerate_missing.py>   # -> filtered-sittings/<t>__<grp>.sittings.jsonl
```

Back up every target `judgments.jsonl` first (gitignored source; no other rollback). Then, with
the **dedicated CEFE Opus judge key** exported as `ANTHROPIC_API_KEY` (the Opus provider reads that
var), per (tradition, group):

```bash
export ANTHROPIC_API_KEY="$ANTHROPIC_JUDGE_API_KEY"   # from taqwabench/.env — the $1k Opus judge key
uv --project workflows/judging run python -m judging judge \
  <filtered>/<t>__<grp>.sittings.jsonl traditions/<t> \
  --results-dir tmp/judging-runs/<layer>/<t> --config tmp/opus-judge.yaml
```

`tmp/opus-judge.yaml` pins the panel to `claude-opus-4-8` (thinking on) — identical to the layer
being completed. Scopes default to `(turn1, full)`; resume skips the scope that already has a
verdict. Up to 3 retries per still-empty cell; a cell still empty after retries is **reported, not
imputed**.
