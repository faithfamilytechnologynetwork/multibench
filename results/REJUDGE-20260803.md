## Why a *filtered* sittings file (the overspend guard)

`judging judge` scores a **whole** `sittings.jsonl` — there is no cell-level flag. Handing it a
full merged sittings file with `--results-dir` at a root that lacks those framings would judge
~21,840 cells (Opus-with-thinking) — hundreds of USD — with **no error**. So the re-judge feeds a
**filtered** sittings file containing only the 34 missing sittings, and the judge's resume set
(`judgments.jsonl` ∩ sittings) reduces the work to exactly the **35** missing cells. A pre-spend
assertion (`work-count == 35`) gates every invocation.

**Transcript source vs verdict layer** (they differ because roots spell subjects differently and
hold different framings):
- **unstated** transcripts ← `20260803-merged/<t>/sittings.jsonl` (canonical subject ids); verdicts
  written into `20260803-unstated-opus/<t>/` (its existing Opus judgments use the same canonical
  spelling → resume matches precisely).
- **stated/guided** transcripts ← `20260823-opus-fullgrid/<t>/sittings.jsonl` (raw provider slugs);
  verdicts written into the same `20260823-opus-fullgrid/<t>/`.

Both layers are picked up by the four-root export order in [`README.md`](README.md).

## Commands (reproducible)

The committed [`results/rejudge_20260803.py`](rejudge_20260803.py) enumerates the currently-missing
Opus cells, writes one **filtered** sittings file per (tradition, framing-group), and prints the
exact `judging judge` command for each plus the total pre-spend work bound. It never spends. From a
builder worktree the source roots are at `../../tmp/judging-runs`:

```bash
uv --project workflows/analysis run python results/rejudge_20260803.py \
  --runs ../../tmp/judging-runs --out tmp/rejudge-120/filtered-sittings \
  --config ../../tmp/opus-judge.yaml --assert-work 35
```

The script computes the **actual post-resume work count** (filtered sitting × scope cells not
already judged in each target layer — exactly what `judge` will bill, mirroring the judge's resume
key). `--assert-work 35` is the **pre-spend guard**: it exits non-zero unless the work count is
exactly 35, so a config/scope/resume-key mismatch (or a full-file mistake) is caught before any
spend. At the time of the run this printed 34 sittings (25 unstated + 9 stated/guided) → **35**
post-resume cells. Each printed command is a per-(tradition, group) **subset** (e.g.
`secular-sage/unstated` = 5); the subsets sum to 35. (Re-running now prints **2** — the residual
cells — since the other 33 are judged; the tool enumerates the *current* gap, so it stays
idempotent. Path note: from a builder worktree the source roots and config are under `../../tmp/`;
from the main checkout drop the `../../`.)

Back up every target `judgments.jsonl` first (gitignored source; no other rollback). Then, with the
**dedicated CEFE Opus judge key** exported as `ANTHROPIC_API_KEY` (the Opus provider reads that
var), run each printed command:

```bash
export ANTHROPIC_API_KEY="$ANTHROPIC_JUDGE_API_KEY"   # from taqwabench/.env — the $1k Opus judge key
uv --project workflows/judging run python -m judging judge \
  tmp/rejudge-120/filtered-sittings/<t>__<grp>.sittings.jsonl traditions/<t> \
  --results-dir ../../tmp/judging-runs/<layer>/<t> --config tmp/opus-judge.yaml
```

`tmp/opus-judge.yaml` pins the panel to `claude-opus-4-8` (thinking on) — identical to the layer
being completed. Scopes default to `(turn1, full)`; resume skips the scope that already has a
verdict. The run was repeated **3 times** (each `judge` call retries a failed provider request up to
3 times internally); a cell still empty after that is **reported, not imputed**.

**Backups.** The 8 target `judgments.jsonl` were copied to the session scratchpad
(`…/scratchpad/backups/`, ephemeral) before appending — not beside the source files. Rollback is
also reconstructible independently by dropping rows with `ts >= 2026-09-05T00:00Z` from the two
target layers (the re-judge added exactly those).

## Results (actuals)

- **Cells re-judged: 33 / 35** over **3 re-judge passes** (each pass = up to 3 per-call attempts).
  Verdict deltas vs backup: unstated-opus judaism +10, roman-catholicism +5, secular-sage +5,
  sunni-islam +1, taoism +4; fullgrid judaism +3, roman-catholicism +1, sunni-islam +4 = **+33**.
- **Residual single-judge cells: 2** — persistent empty/truncated Opus responses after ≥9 provider
  attempts each; **reported, not imputed** (architect-approved, 2026-09-05). These use their single
  (Gemini) verdict; the combined score is still defined on all 93,420 cells. Recorded in the
  manifest `ranking.single_judge_cells` (Phase 2/4) and here:
  1. `judaism | gemini-3.6-flash (subject) | MSR-025 | insistence | unstated | full`
  2. `sunni-islam | Qwen/Qwen3-235B-A22B-Instruct-2507 | JLS-122 | flattery | guided | full`
- **New `judgments_v2.jsonl` rows: 0** (confirmed — the layers are Opus-only, so the disagreement
  re-judge pass is a no-op; `rejudge_cells: 0` in every summary).
- **Spend (dedicated CEFE judge key), ceiling 20 USD:**
  - **Measured (exact, usage-computed): $11.02** — the 33 persisted verdicts (in=88,095, out=109,679,
    cache_write=69,882, cache_read=107,832 tokens; Opus-4.x rates $15 / $75 / $18.75 / $1.50 per 1M
    input / output / cache-write / cache-read).
  - **Estimated (not persisted): ~$1–3** — the **48 failed provider calls** (16 failed cell-attempts
    × 3 internal retries; 14 empty responses → ~0 output, 2 truncated). Failed calls emit no verdict
    row, so their usage isn't recorded. They are input-dominated and mostly hit the cached prompt
    prefix; a no-cache worst case on input alone is ≈ $5.8. Note the Anthropic judge caps output at
    `max_tokens=4096`, so a strict per-call output bound exists but empty responses carry ~0 output.
  - **Conservative upper bound ≈ $17, under $20** (independently derived in the phase review): 48
    failed calls × the per-call input/cache mean (~$0.085/call, uncached worst case) ≈ $4.1 input;
    output ~0 for the 14 empties and capped at `max_tokens=4096` (~$0.31) for the 2 truncated ≈
    ≤$2. So measured $11.02 + ≤~$6 ⇒ ≤ ~$17 pessimistic; realistic ≈ $12–14.
  - **Best estimate ≈ $12–14, comfortably under $20.** Anthropic **console delta: not checked**
    (architect-accepted, 2026-09-05 — neither builder nor architect has console access from here;
    the measured $11.02 + estimated failed overhead was deemed sufficient evidence against the $20
    cap). The dedicated judge key means a console read, if ever done, would show exactly this run.
- **Post-run verification:** enumeration over the four roots confirms both judges cover the full
  canonical universe except the 2 documented residual cells; Gemini has 0 gaps.
  `test_grid_completeness.py` encodes this (skips where the gitignored roots are absent).
