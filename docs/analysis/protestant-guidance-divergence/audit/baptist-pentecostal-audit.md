# Citation audit — baptist and pentecostal columns

Adversarial sampled audit per `method.md` §Verification (guilty-until-confirmed). Auditor posture:
every citation treated as wrong until positively confirmed against a standard published edition.

**Sample** (fixed five questions per column): Q05, Q15, Q24, Q37, Q47.

**Verification channel.** The network egress proxy blocks direct fetch of bfm.sbc.net, sbc.net,
ag.org, the1689confession.com, bible-researcher.com, en.wikipedia.org, and evangelicalarminians.org.
Web *search* was reachable and returned result snippets quoting the standard editions; all
"confirmed (online)" verdicts below rest on verbatim or near-verbatim snippet matches from
bfm.sbc.net / baptistpress.com (BF&M 2000), ag.org-indexed pages (AG Fundamental Truths and
position papers), and 1689-confession sites. Canonical Scripture references were verified against
the biblical text directly (reference + wording checks); these are marked "confirmed (Scripture)".
Items that could be checked neither way beyond conservative background knowledge are marked
unverified-online and were left with (or moved to) suitably hedged flags.

Verdicts: **confirmed** / **corrected** (worksheet edited) / **downgraded** (flag reduced) /
**unverified-online** (kept, flagged conservatively; could not be checked through the proxy).
