# Adversarial citation audit — `lutheran` and `anabaptist` columns

**Sample** (per method.md §Verification, fixed): Q05, Q15, Q24, Q37, Q47 per column.
**Posture**: guilty until confirmed — every citation treated as wrong until positively grounded.
**Date**: 2026-08-22.

**Verification sources.** Direct fetches of bookofconcord.org, gameo.org, mennoniteusa.org,
anabaptistwiki.org, and gutenberg.org were blocked by the network egress proxy; verification was
done via web search, which returned quoted text of the same standard editions (Augsburg Confession
per the Triglot/Book of Concord text; Small/Large Catechism per CPH/ELS editions; Schleitheim per
the Wenger translation; Dordrecht per the 1632 eighteen-article English text; CFMP 1995 per the
Mennonite Church USA published articles). Universally attested Scripture texts were confirmed from
knowledge where no search anchor was needed; marked "(knowledge)". No item had to be left
unverified-online.

Verdicts: **confirmed** (positive grounds found, kept as written) · **corrected** (edited in
place) · **downgraded** (confidence flag cut) · **unverified-online** (none).
